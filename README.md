# 갤럭시 → 아이폰 선택 SMS 공유 (1차 시험판)

## 기능
- 특정 발신번호로 들어온 SMS를 지정한 아이폰 번호로 자동 SMS 재전송
- ON/OFF 스위치, 발신번호/받을번호 입력 및 저장
- 서버/아이폰 앱 불필요. 문자는 갤럭시 SIM 회선을 통해 발송됨
- 앱을 화면에 띄우지 않아도 Android SMS_RECEIVED 방송으로 처리

## 실행
1. Android Studio에서 이 폴더를 프로젝트로 열기 (JDK 17 권장)
2. Gradle sync, 갤럭시 USB 연결 후 Run 또는 Build APK
3. 갤럭시에서 수신·전송 권한 허용
4. 감시 발신번호 및 아이폰 전화번호 입력, ON 선택 후 [설정 저장]
5. 소유한 테스트 발신번호로 갤럭시에 SMS를 보내 전달 여부 확인

## 주의
- 이 파일은 **소스 프로젝트**로 APK 파일이 아닙니다. 실제 단말에서 빌드/테스트하지 않았습니다.
- MMS/RCS/카카오톡 알림은 대상이 아니며 일반 SMS만 지원합니다.
- `전송 요청`은 실제 통신사 전송/아이폰 도착 성공의 보장이 아닙니다.
- 복수 SIM이라면 기본 문자 발송 SIM을 갤럭시 설정에서 지정해야 합니다.
- SMS 재전송에 문자 요금이 발생할 수 있으며 긴 문자는 여러 건으로 나뉠 수 있습니다.
- 휴대폰 권한과 제조사 배터리 제한에 따라 동작이 달라집니다.
- Play Store는 SMS 수신·발송 권한이 있는 앱에 엄격한 배포 심사가 있습니다. 개인 설치 테스트가 목적입니다.
- 앱 접근 권한을 가진 사람이 번호/ON 설정을 바꿀 수 있으므로 휴대폰 잠금 보호가 필요합니다.
- 발신번호는 숫자 기준 완전 일치 방식입니다. 국제번호(+82) 표기가 다른 경우 등록한 값에 맞춰야 합니다.

## Android Studio 없이 APK 만들기 (GitHub Actions)
1. GitHub에서 새 저장소(repository)를 만들고 이 프로젝트의 *내용물*을 저장소 루트에 올립니다. `.github/workflows/build-apk.yml` 파일도 반드시 포함해야 합니다. GitHub 웹 업로드가 숨김 폴더를 건너뛰면 `.github` 경로를 따로 추가하세요.
2. GitHub 저장소에서 Actions → Build Android APK → Run workflow를 클릭합니다. main 또는 master에 push해도 자동 빌드합니다.
3. 성공한 작업의 Artifacts에서 `SMSRelayGalaxy-debug-apk`를 받습니다.
4. 받은 zip에서 `app-debug.apk`를 꺼내 갤럭시에 복사하고 실행합니다. 보안 경고가 나오면 출처를 확인한 뒤 설치 권한을 허용해야 할 수 있습니다.
5. 앱에서 수신/전송 SMS 권한을 허용하고 감지할 발신번호 및 아이폰 번호를 입력한 다음 ON → 설정 저장하세요.

참고: 빌드 설정은 추가했지만 이 환경에서는 Android SDK/Gradle이 없어 실제 빌드 성공을 검증하지 못했습니다. debug APK는 개인 설치 테스트용입니다. Galaxy의 소프트웨어 정책에 따라 SMS 권한에 추가적인 제한이 있을 수 있습니다.
